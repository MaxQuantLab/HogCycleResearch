# 猪周期研究台

**MaxQuant Labs · 中国生猪市场数据与周期研究**

**在线访问：[猪周期研究台 · GitHub Pages](https://maxquantlab.github.io/HogCycleResearch/)**

## 项目介绍

猪周期研究台是一个面向生猪市场学习与研究的交互式可视化网站。项目从“猪价为何处于低位、母猪存栏下降为何没有立即带来肉量下降、哪些信号可能指向周期反转”等问题出发，把价格、产能、成本和消费数据放在同一张时间表上，帮助读者观察供需变化与传导时滞。

研究以2016—2025十年历史数据为基础，补充2026年已取得数据；默认窗口包含2026年已公布观测。网站提供来源链接、口径说明与缺失标记，方便逐条核查数据和研究结论。

## 主要功能

- **市场全景**：查看猪粮比、能繁母猪存栏、生猪价格和猪肉产量的历史轨迹，以及核心指标快照和猪粮比月历。
- **指标对照**：选择指标与时间窗口，比较原始值、指数或同比变化，并观察领先月数与样本相关性。
- **周期研究**：梳理母猪存栏、繁殖效率、出栏、体重、成本与需求的传导关系，观察产能调减与供给收缩的时间差及反转条件。
- **数据与来源**：浏览指标目录、覆盖范围与原始来源，下载结构化数据，区分真实观测、反推值和计算值。
- **期货学习**：提供生猪期货保证金与杠杆的示例计算，帮助理解合约规模和资金占用。

## 数据覆盖

当前研究快照整理了63项数据指标、1,877条观测与164条来源记录，另列24项待补因素。覆盖价格与猪粮比、母猪及生猪存栏、出栏与屠宰、猪肉产量、饲料与养殖成本、进出口、居民消费与收入等维度。

12项年度序列完整覆盖2016—2025年；月度、季度与期货数据覆盖不齐，各指标的最新统计期不同。2026年全年猪肉产量尚未公布，页面保留已公布的前三季度累计值及其口径。

## 数据

- 63项数据指标，24项待补因素；12项年度序列完整覆盖十年。
- 数值来源主要为全国畜牧总站、农业农村部联合月报、国家统计局年度报告及官方统计公报。
- 明确标识官方表转载、原表同期值、原表上月值、环比反推及计算值。
- 猪粮比口径不混用；2025年7月屠宰量范围变化后拆成两个序列。
- 不补零、不插值、不将旧观测延续到当前；不将季度累计当成单季度。
- 保留年度原始发布版本，可能与后续修订的同比基数不同。

`dist/`仅包含原创页面、结构化数字及来源链接，不发布抓取的网页全文。
`research/`保存整理脚本与结构化中间数据。网页全文仅作临时核验，不随版本发布；重新从原始网页整理时需先取得相应来源记录，依次运行build_data.py、supplement_data.py、extend_history.py和finalize_data.py（自动应用research/updates/中的核验批次）。

## 验证

`node research/verify.mjs`检验数据唯一性、日期及单位结构、十年窗口与覆盖、缺失期、原口径截止、日历滞后、同比、相关性、保证金计算、页面初始化与控件共享状态。
DOM与WebMCP注册验证使用适配器，不能代替真实浏览器视觉验收。此前GitHub Pages版本已在浏览器中确认首页和历史图表正常加载；本次更新通过项目的数据与页面功能校验。

## 本地运行与发布

前端使用HTML、CSS与JavaScript，静态页面位于`dist/`，无需前端构建步骤。在仓库根目录运行：

```bash
python3 -m http.server 8000 --directory dist
```

然后打开`http://localhost:8000`。

GitHub Pages使用`.github/workflows/static.yml`自动部署`dist/`。提交到`main`分支会触发重新发布，也可以在GitHub Actions中手动运行工作流。自动部署仅发布仓库中的现有文件，不会自动采集或更新市场数据。

## 边界

快照按核验批次发布，不提供实时行情，不作因果识别或交易预测。
数据以统计期而非当时可获得日期对齐，不适用于无前视偏差回测。
LH计算的10680元/吨来自用户此前报价、10%保证金率为示例假设；不代表当前价格或当前保证金率。

此前补充：2021—2025年猪饲料、工业饲料、全国人口和名义可支配收入；2021/2025年部分LH年度成交持仓统计。期货年度数据不接续为每日行情，不插值缺失年份。饲料报告网页迁移日期与统计年度分别识别。

十年扩展补充311条2016—2020观测。年度猪肉、出栏、存栏、替代肉、禽蛋、玉米、收入、餐饮及每头猪肉产出代理覆盖2016—2025。早期生猪月均价与猪粮比只采用取得的官方月报及原表同期数，覆盖不齐；2016—2018年能繁母猪未取得可比存栏头数，保留为空。生猪期货2021年上市，上市前没有LH交易数据。年度柱图保留十个年份，缺失年度显示空位。
