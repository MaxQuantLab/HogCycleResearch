# 猪周期研究台

一次性中国生猪市场研究快照，2021—2025为五年窗口，补充2026已取得数据。

## 数据

- 62项数据指标，24项待补因素；25项年度序列完整覆盖五年。
- 数值来源主要为全国畜牧总站、农业农村部联合月报、国家统计局年度报告及官方统计公报。
- 明确标识官方表转载、原表同期值、原表上月值、环比反推及计算值。
- 猪粮比口径不混用；2025年7月屠宰量范围变化后拆成两个序列。
- 不补零、不插值、不将旧观测延续到当前；不将季度累计当成单季度。
- 保留年度原始发布版本，可能与后续修订的同比基数不同。

`dist/`仅包含原创页面、结构化数字及来源链接，不发布抓取的网页全文。
`research/`保存整理脚本与结构化中间数据。网页全文仅作临时核验，不随版本发布；重新从原始网页整理时需先取得相应来源记录，依次运行build_data.py、supplement_data.py和finalize_data.py。

## 验证

`node research/verify.mjs`检验数据唯一性、日期及单位结构、五年覆盖、缺失期、原口径截止、日历滞后、同比、相关性、保证金计算、页面初始化与控件共享状态。
DOM与WebMCP注册验证使用适配器，不能代替真实浏览器视觉验收；当前环境没有可用的允许预览或支持WebMCP的浏览器上下文。

## 边界

快照不自动刷新，不提供实时行情，不作因果识别或交易预测。
数据以统计期而非当时可获得日期对齐，不适用于无前视偏差回测。
LH计算的10680元/吨来自用户此前报价、10%保证金率为示例假设；不代表当前价格或当前保证金率。

本轮补充：五年猪饲料、工业饲料、全国人口和名义可支配收入；2021/2025年部分LH年度成交持仓统计。期货年度数据不接续为每日行情，不插值缺失年份。饲料报告网页迁移日期与统计年度分别识别。
